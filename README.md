## M031TD2AE, M031EC1AE  
---
[M031TD2AE](https://www.nuvoton.com/products/microcontrollers/arm-cortex-m0-mcus/m031-series/m031td2ae/) Nuvoton NuMicro M031TD2AE
 is low-voltage operation MCU based on Arm® Cortex®-M0 core with 32-bit hardware multiplier/divider. Operating frequency up to 48 MHz
 with 1.8V ~ 3.6V operating voltage, equipped 64 KB Flash and 8 KB SRAM. M031TD2AE also provides plenty of peripherals included up to 
 1 set Universal Serial Control Interface ( USCI ) , 3 set UART , 1 set SPI /I²S, 2 set I²C , 10-ch 12-bit ADC , 12-ch 16-bit PWM etc. 
 for various application demand. And it can operate over a wide temperature range as - 40°C~ + 105°C.  

|   *Title* | *Parameter* | 
|:----------|:------------|
|Chip       |M031TD2AE    | 
|Arch       |Arm® Cortex®-M0| 
|Freq       | 48 MHz      | 
|Flash      |64 KB Flash  | 
|RAM        |8 KB SRAM    |
|Package    |QFN33(4x4 mm)|
